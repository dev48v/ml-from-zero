MachineLearningFromZero · Day 51

🗳️ RANSAC (RANdom SAmple Consensus) — fit a model that flatly ignores the outliers that wreck least-squares. Ordinary least squares minimises squared residuals, so a single far-off point yanks the whole line toward itself — its breakdown point is zero: one bad measurement can ruin the fit. RANSAC throws that away and does something almost cheeky instead: repeatedly grab the minimum number of points a model needs (just 2 for a line), fit it exactly, then count how many of the other points fall inside a threshold band — that count is the consensus. Keep the model with the largest consensus set, then refit least-squares on those inliers alone for precision. Because each guess is built from a clean minimal sample, outliers never get averaged in — they simply fail to vote. The number of random tries you need follows a tidy probability law N = log(1−p) / log(1−wˢ) that explodes as the inlier fraction w drops. Everything below runs live in your browser — scatter heavy outliers (click to add your own), watch RANSAC animate its random 2-point samples with the inlier band and count per iteration, converge to the robust line, and see ordinary least-squares get dragged away for contrast — with sliders for threshold, iterations, and outlier count.

Least squares has no defence against a single bad point. Because it minimises the sum of squared vertical residuals, a lone outlier — whose squared error is enormous — can pivot the entire fitted line away from every honest measurement. Its breakdown point is zero: corrupt one observation and the estimate is arbitrarily wrong. RANSAC takes the opposite stance. Rather than trusting every point at once, it hypothesises a model from the smallest random subset that defines it — for a line, two points — checks how many of the remaining points agree with that hypothesis to within a threshold, and repeats. The hypothesis with the widest agreement wins, and a final least-squares pass on its inliers alone sharpens it. Outliers are never fitted; they only ever fail to consent. Below it is built from scratch, live — the random minimal samples, the inlier band, the consensus count per iteration, the convergence to a robust line, and the least-squares line being dragged off course — on points you place yourself.

N = ⌈ log(1 − p) / log(1 − wˢ) ⌉
Where it comes from. One random sample is all-inlier with probability wˢ. So it fails with probability 1−wˢ, and N independent samples all fail with probability (1−wˢ)ᴺ. Demand that this be at most 1−p (i.e. succeed at least once with confidence p) and solve for N. The curse: N grows exponentially in the sample size s and blows up as w → 0 — which is why RANSAC loves minimal samples and struggles when outliers dominate.

🔨 Build it yourself

    
RANSAC is astonishingly little code — the exact routine the LOOK tab runs, no scikit-learn black box. Below is the runnable core: fit a line from the two-point minimal sample, score a model by how many points consent to it, loop random samples keeping the widest consensus, compute how many loops you actually need from the inlier fraction, and polish the winner with a least-squares refit on its inliers. Every line the LOOK tab draws comes from these snippets.

    
    
      
  1. 
        
    1
    The minimal sample — a line from exactly 2 points
    
        
    A model needs s points, where s is its degrees of freedom — for a line, two. Fitting from the minimum is the whole trick: with only two points there is no averaging, so a sample of two inliers gives a clean line, and you never dilute a good hypothesis by mixing outliers in. (A vertical pair has infinite slope — just skip it and draw again.)
    
        
    // a line needs exactly 2 points (its degrees of freedom)
function fitLine(p, q) {
  const dx = q.x - p.x;
  if (Math.abs(dx) < 1e-9) return null;     // vertical pair → skip this sample
  const m = (q.y - p.y) / dx;
  return { m, b: p.y - m * p.x };           // y = m·x + b
}

  2. 
        
    2
    The consensus score — count the inliers
    
        
    This replaces least-squares' sum-of-squares. A point is an inlier if its residual to the candidate line is within a threshold t; the model's score is simply how many inliers it has. Counting is bounded — an outlier a mile away adds nothing beyond "not an inlier" — so a single wild point can never dominate the score the way it dominates a squared-error sum.
    
        
    const residual = (pt, {m, b}) => Math.abs(pt.y - (m * pt.x + b));

function consensus(pts, model, t) {
  const inliers = [];
  for (let i = 0; i < pts.length; i++)
    if (residual(pts[i], model) <= t) inliers.push(i);  // inside the band
  return inliers;                                       // its SIZE = the score
}

  3. 
        
    3
    The loop — sample, score, keep the best
    
        
    That is the entire algorithm. Draw a random minimal sample, fit it, score its consensus, and remember the model with the most inliers. Repeat for a fixed budget of trials. No gradients, no matrix inverse in the loop — just a competition where the biggest agreeing crowd wins.
    
        
    function ransac(pts, t, iters) {
  let best = { inliers: [], model: null };
  for (let k = 0; k < iters; k++) {
    const [i, j] = twoDistinct(pts.length);         // random minimal sample
    const model = fitLine(pts[i], pts[j]);
    if (!model) continue;
    const inliers = consensus(pts, model, t);
    if (inliers.length > best.inliers.length)       // widest consensus wins
      best = { inliers, model };
  }
  return best;
}

    How many trials — the probability formula
    
        
    You do not guess the iteration count — you compute it. If a fraction w of points are inliers, a minimal sample of s is all-inlier with probability wˢ. To hit at least one clean sample with confidence p, solve (1−wˢ)ᴺ ≤ 1−p. Good RANSAC updates w from the best consensus so far and shrinks N adaptively as it finds better models.
    
        
    function trials(w, s = 2, p = 0.99) {
  return Math.ceil(Math.log(1 - p) / Math.log(1 - Math.pow(w, s)));
}
// w=0.5 → 17   w=0.3 → 49   w=0.1 → 459    (explodes as outliers grow)
// adaptive: after each better model, set w = bestInliers / n and recompute N

    Refit on the consensus set — polish the winner
    
        
    The winning two-point line is only as good as its two points. Now that you know which points are inliers, throw least-squares at all of them at once — and only them. This is where the precision comes from: robust selection first, efficient estimation second. (Some implementations then re-count inliers and refit again until stable.)
    
        
    function olsFit(pts, idx) {                 // least squares on INLIERS ONLY
  const S = idx.map(i => pts[i]), n = S.length;
  let sx=0, sy=0, sxx=0, sxy=0;
  for (const p of S) { sx+=p.x; sy+=p.y; sxx+=p.x*p.x; sxy+=p.x*p.y; }
  const m = (n*sxy - sx*sy) / (n*sxx - sx*sx);
  return { m, b: (sy - m*sx) / n };
}
const { inliers } = ransac(pts, t, iters);
const robust = olsFit(pts, inliers);       // ← the final, precise line

    In practice — the standard tools
    
        
    You will rarely hand-roll it. scikit-learn's RANSACRegressor wraps any base estimator with a residual threshold and trial budget and hands back the refit model plus an inlier mask. For geometry — line, plane, homography, fundamental matrix — scikit-image's ransac and OpenCV's findHomography(..., cv2.RANSAC) are the workhorses that made RANSAC a computer-vision staple.
    
        
    # scikit-learn — robust regression
from sklearn.linear_model import RANSACRegressor, LinearRegression
r = RANSACRegressor(LinearRegression(),
                    residual_threshold=0.6,   # your inlier band
                    max_trials=100).fit(X, y)
robust_line = r.estimator_        # least-squares refit on inliers
inlier_mask = r.inlier_mask_      # boolean: which points it kept

# scikit-image — geometry (lines, planes, homographies)
from skimage.measure import ransac, LineModelND
model, inliers = ransac(points, LineModelND, min_samples=2,
                        residual_threshold=0.6, max_trials=100)

The trade is how much contamination you expect. OLS is optimal when noise is Gaussian and there are no outliers, and useless the instant there is one high-leverage point. Huber (Day 52) keeps least-squares' smoothness but grades residuals down to linear past a knee, tolerating mild outliers while still bending toward a bad high-leverage point. Theil–Sen takes the median of all pairwise slopes — elegant and deterministic, robust to ~29% contamination, but O(n²). RANSAC is the tool when outliers are many and you can name a threshold: it makes no smoothness assumption, tolerates well over half the data as garbage, and dominates geometric vision (homographies, fundamental matrices, point-cloud fitting) — at the price of randomness, a threshold to set, and an iteration budget that grows as the inlier fraction falls. Least median of squares reaches the theoretical 50% breakdown with no threshold, but the search is costly. RANSAC's genius is the minimal sample: fit from the fewest points possible so a clean guess needs only a few good points to coincide, then let consensus and a final refit do the rest.

    


    
🎉 Day 51 of MachineLearningFromZero done — a fit that ignores the outliers instead of drowning in them.
RANSAC replaces least-squares' fatal trust in every point with a vote. Rather than minimising a squared error that one far-off point can dominate, it hypothesises a model from the smallest random sample that defines it — 2 points for a line — counts how many other points fall within a threshold band (the consensus set), keeps the model with the widest agreement, and refits least-squares on those inliers alone. Because good hypotheses are built from clean minimal samples, outliers never get averaged in — they only ever fail to consent, so the breakdown point climbs from OLS's 0% to well past 50%. The number of random tries you need is not a guess but a formula, N = log(1−p)/log(1−wˢ), that grows exponentially in the sample size s and explodes as the inlier fraction w shrinks — the reason RANSAC prizes minimal samples and struggles when outliers truly dominate. Set the threshold from your noise scale (roughly 2–3σ), the confidence and inlier guess set the budget, and a final refit gives the precision. 👉 The moment your data has gross outliers — bad correspondences, sensor glitches, mislabels — and squared error is dragging your model off the truth, stop trusting every point and start sampling for consensus.
