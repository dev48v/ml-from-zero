MACHINELEARNINGFROMZERO · DAY 69

📏 Measurement error in a predictor — every column in every dataset is a recording of something, and the recording is not the thing. Write w = x + u: you fit on w, the world runs on x. The textbook consequence is attenuation — the slope comes back multiplied by the reliability λ — and the textbook reaction is that it is conservative, so never mind. This page builds the whole family of worlds that produce the identical observed data: one (w, y) pair of arrays, and a continuum of structural truths behind it, the true slope running from the fitted one up to the fitted one divided by the observed R² — the Frisch bound, derived here as σε² ≥ 0 rather than quoted. Every diagnostic you would reach for is bit-identical across the family, and the same 95% interval covers the truth 95.3% of the time in one member and 0.0% in another. Then the part nobody warns you about: mismeasure one predictor and the coefficient on a perfectly measured one moves too — a variable with an effect of exactly 0.000 is fitted at 0.4636, |t| = 9.8 at a thousand rows and 68.8 at forty thousand, and it outranks the variable that does have an effect. Pure vanilla JavaScript, one file, no build step.

The observed law is fixed: Var(w) = 1, Var(y) = 2, corr(w, y)² = R², so the population least-squares slope of y on w is c = √(R²·2) whatever else is true. A world is then a choice of λ: the true slope is β = c/λ, the error variance is σ²u = 1 − λ and the residual variance is σ²ε = 2 − c²/λ. That last one has to be non-negative, which is the entire constraint: λ ≥ R². Every number below is averaged over 25 seeds unless it says otherwise.

Every row was handed the same (w, y) arrays — the same object, not a copy. So the fitted-slope and interval columns are identical for a structural reason, and only the truth column moves. Coverage is measured over 400 fresh datasets, and because the interval does not depend on the world, all six coverages are read off the same intervals. The last column is not a second measurement — it is the closed form Φ(q − δ) − Φ(−q − δ) with δ = (β − c)√n / s, so the measured column has something to be wrong against.

IN-PAGE SELF-TEST

The column is a recording, not the thing

Self-reported income, a survey scale, a sensor reading, last month's spend pulled from a system that rounds, "years of experience" typed into a form, a proxy like postcode standing in for wealth. In every case the model is fitted on w and the world runs on x, and the gap between them is not a modelling choice — it is a property of the instrument.

The classical error model is three lines:

x            latent truth,  Var(x) = σ²ₓ
w = x + u    the recording, u ⊥ x,  Var(u) = σ²ₖ
y = a + βx + ε   the world,     ε ⊥ (x, u)

Define the reliability λ = σ²ₓ / (σ²ₓ + σ²ₖ) — the share of the recorded column's variance that is signal. Then the population least-squares slope of y on w is

plim β̂OLS = Cov(w, y)/Var(w) = βσ²ₓ / (σ²ₓ + σ²ₖ) = λβ

That is attenuation, or regression dilution: the coefficient is shrunk towards zero by exactly the reliability. It is usually presented as reassuring — the effect is real and you are underselling it. Two things are wrong with that reading, and both are measured on the MEASURE tab.

The observationally equivalent family

Fix the observed law. Standardise so Var(w) = 1, and write c = Cov(w, y), v = Var(y). Under the classical model a world is one number, λ, and every structural quantity is forced:

β   = c/λ
σ²ₖ = 1 − λ
σ²ₕ = v − c²/λ

The only constraint in the whole problem is that a variance cannot be negative:

σ²ₕ ≥ 0   ⇔   λ ≥ c²/v = R²   ⇔   c ≤ β ≤ v/c

So the true slope is not identified — it lives in an interval whose lower end is the slope you fitted and whose upper end is v/c, which is the reciprocal of the reverse regression (w on y). That is the classical Frisch bound, and the page arrives at it as a non-negativity condition rather than importing it.

The width of that interval is 1/R². A model with R² = 0.50 has a true slope somewhere in a 2× range; at R² = 0.10 the range is 10×. The worse your fit, the less the data pins down the mechanism — which is the opposite of the instinct that a weak fit means a small effect. A weak fit is equally consistent with a large effect measured badly.

Why the family shares its data exactly

The page does not simulate each world and hope the datasets look alike. It draws the observed data once, from three independent standard normals, and then reconstructs each world's latents as a linear map of the same three:

w = z₁
y = a + c·z₁ + s·z₂                      s = √(v − c²)

x = λz₁ + (c(1−λ)/s)z₂ + √(λ(1−λ) − c²(1−λ)²/s²) z₃
u = w − x,   ε = y − a − βx

Because everything is a linear combination of jointly Gaussian coordinates, "uncorrelated" upgrades to "independent" for free, so the classical model's independence assumptions hold exactly rather than approximately. The page checks the three inner products <x,u>, <x,ε>, <u,ε> are zero and that the three variances land on λ, 1−λ and v−c²/λ. The last coordinate z₃ is what makes it possible at all: with only two noise directions the system is over-determined and has solutions at λ = 1 and λ = ½ only.

The coefficient on z₃ is real exactly when λ ≥ R² — the same bound, arrived at a second and completely different way. That agreement is one of the self-tests.

Berkson error: the same noise, the opposite consequence

There is a second error model that looks identical on a scatterplot and behaves in the opposite way. In Berkson error the recorded value is the fixed one and the truth scatters around it:

classical:  w = x + u,  u ⊥ x    ⇒  Cov(w, u) = σ²ₖ,  Cov(x, u) = 0
Berkson:    x = w + u,  u ⊥ w    ⇒  Cov(w, u) = 0,   Cov(x, u) = σ²ₖ

This is not exotic. It is what you have whenever the recorded value is a target, a setting, a nominal dose, a bucket label or a rounded grid point: everyone in the "40–49" band is recorded as 45 and their true ages scatter around it. And the consequence is completely different — y = a + β(w + u) + ε = a + βw + (βu + ε), with u ⊥ w, so the regression of y on w has slope exactly β. No attenuation at all, only a fatter residual.

Both families are on the page and both reproduce the identical observed arrays. So the data is consistent with "the slope is too small by a factor of λ" and with "the slope is exactly right and the residual is inflated" simultaneously. The thing that separates them — whether u is independent of the truth or of the recording — is a statement about u, and u is never observed. It is a fact about the instrument, and it has to come from whoever built the instrument.

Attenuation is optimal for prediction, which is the trap

Given that you will only ever have w at prediction time, the attenuated coefficient is not a mistake — it is the answer. λβ is the coefficient of the best linear predictor of y from w, so its risk is v − c², and substituting the correct structural β raises the risk by exactly (c − β)². On the default settings that is a 2.00× increase in test MSE from using the unbiased number, and the value at the Frisch bound is 1/R² exactly.

So the two questions come apart completely:

  • "What will y be, given the recording I will have?" — the fitted model is right, attenuation and all. Nothing needs fixing.
  • "How much does x move y?" — the fitted model is wrong by a factor the data cannot supply, and a better holdout score means nothing.

Every validation habit in machine learning answers the first question. That is why this failure mode survives review: the model is genuinely good, the residuals are genuinely clean, the holdout is genuinely honest, and the coefficient is genuinely not the effect.

The bias does not stay in its own column

With one predictor, attenuation at least points in a known direction. With two it stops being conservative. Let x₁ be mismeasured with d = (1−λ₁)/λ₁, let x₂ be recorded perfectly, and let ρ be their correlation. The population coefficients are (Σ + D)⁻¹Σβ, and the 2×2 case is small enough to write out:

β̂₁ = β₁(1 − ρ²) / (1 + d − ρ²)
β̂₂ = β₂ + dρβ₁ / (1 + d − ρ²)

The second term is the whole problem. It is zero only if ρ = 0, or β₁ = 0, or the measurement is perfect. Otherwise the coefficient on the column you measured perfectly is biased, by an amount that has nothing to do with β₂:

  • Set β₂ = 0 exactly. At ρ = 0.7 and λ₁ = 0.5 the fitted β̂₂ is 0.464 — a variable with no effect at all, reported with a large t statistic that grows with n.
  • It is larger than β̂₁ = 0.338, so the two predictors swap places in any importance ranking. The variable that matters looks secondary to the one that does not matter at all.
  • The sign flips whenever β₂ < −dρβ₁/(1 + d − ρ²), and the page locates that threshold and prints it.
  • β̂₁ is attenuated by (1−ρ²)/(1+d−ρ²), which is worse than λ₁: 0.338 against the single-predictor 0.500. Correlated predictors amplify the dilution rather than absorbing it.

"Conservative" is a one-predictor statement, and it does not generalise. This is also the cleanest reason to distrust a coefficient table as a variable-importance story: one noisy column redistributes signal onto whichever columns it correlates with.

What actually fixes it

Nothing that is a function of (w, y) alone can, because the family shares that function. Every repair works by adding information from outside it:

  • A known λ — from a calibration study, an instrument specification, a validated scale. Then β̂/λ is unbiased and its interval just scales. This is the honest version of "assume something".
  • A replicate measurement. Record the same quantity twice with independent errors and corr(w₁, w₂) = λ exactly. The parameter that was unidentifiable becomes a correlation coefficient. This is the important one: the fix is a change to the data collection, not to the estimator.
  • An instrument. Anything correlated with x and unrelated to ε works, and a replicate is the easiest instrument there is: β̂IV = Cov(w₂, y)/Cov(w₂, w₁) → β, since the numerator is βσ²ₓ and the denominator is σ²ₓ and the errors cancel out of both.
  • A validation subsample where the gold-standard x is available for some rows — regression calibration, the same idea with a different budget.

All four are priced on the page, with measured coverage. The one that is not on the list is more data: it is measured instead, and it moves coverage in the wrong direction.

The honest caveat about this page

Gaussian everything, a correctly specified linear model, homoscedastic error, and measurement error that is additive, mean-zero and independent — the friendliest possible version. That is deliberate: it removes every other source of trouble, so what is left is the instrument. Real measurement error is often differential (correlated with y), which is strictly worse and can bias in either direction, or multiplicative, or heaped on round numbers. The structural claims — the shared observed data, the Frisch bound, the exact β̂₂ formula, the replicate identity — do not depend on the friendly settings. The specific magnitudes do.

🔨 How it is built

1. A sampler that does not know which world it is in

sampleBase(n, cfg, seed)            // -> { obs:{w,y}, z1, z2 }   NO lambda, NO kind
classicalWorld(base, cfg, lambda)   // -> { obs: base.obs, x, u, eps, beta }
berksonWorld(base, cfg, theta)      // -> { obs: base.obs, x, u, eps, beta }

Every world returns base.obs — the identical object, asserted with ===. "The observed data is the same" is therefore not a numerical coincidence the page checks afterwards; it is the only thing that could have happened. The third noise direction z₃ is drawn lazily and memoised on the base, so worlds built from one base share it too and the latent comparison is apples to apples.

2. The latents are a closed-form linear map, and it is derived

a₁ = λ                        <- forced by Cov(x, u) = 0
a₂ = c(1 − λ)/s               <- forced by Cov(x, ε) = 0
a₃² = λ(1 − λ) − a₂²         <- forced by Var(x) = λ
Cov(u, ε) = 0 and Var(u) = 1 − λ and Var(ε) = v − c²/λ   fall out

Three of the six conditions determine the map and the other three are then satisfied automatically — which is the interesting part, because it means the classical model is exactly as flexible as one parameter and no more. The page verifies the automatic ones rather than assuming them, on a grid of λ. u and ε are built from their own coefficients, never as w − x, so x + u = w is a real check on the algebra instead of a tautology.

3. Where the tolerance is, and why

|x + u − w|      < 1e-13     // not ===
|a + βx + ε − y| < 1e-13     // not ===

These are exact algebraic identities and they still fail bit-equality, and the reason is worth being precise about, because the obvious suspect is not the culprit. The coefficient vectors are exact: a₁ + b₁ = 1 to the bit for every λ on a 41-point grid, and the z₁ coefficient of ε — c − (c/λ)λ, the term you would expect to be one ulp off — is exactly 0 at most λ and never worse than 1.1e-16. What actually breaks it is summation order: (a₁z₁ + a₂z₂ + a₃z₃) + (b₁z₁ + b₂z₂ + b₃z₃) is not (a₁+b₁)z₁ + … in binary64, which lands the rebuild at 4.4e-16 on w and 8.9e-16 on y. Day 68 hit the identical wall on a mean-imputation identity at 1.6e-15, and the same rule applies: a === that has to be relaxed is worth leaving visible with its reason attached rather than quietly widened, and the reason should be the real one. The observed arrays themselves are compared with ===, because there the claim is object identity, not arithmetic.

4. The interval is computed once and scored six times

for each replication:
    base = sampleBase(n, cfg, seed)          // world-free
    fit  = ols(base.obs.w, base.obs.y)
    lo, hi = fit.b ± t₀.₀₃₅(n−2)·fit.se
    for each world: coverage[world] += (lo ≤ world.beta ≤ hi)

One loop, six coverages, literally the same endpoints. That is what makes the headline a structural statement instead of a comparison of two simulations that happen to differ. The t quantile is a Cornish–Fisher expansion, checked in the verifier against a numerically integrated Student-t CDF.

5. Population coefficients, not large-sample estimates

b = solve(Σₓₓ + D, Σₓₓβ)                      // Gaussian elimination, exact
β̂₂ = β₂ + dρβ₁/(1 + d − ρ²)             // closed form, asserted equal to 1e-12

The two-predictor table has an exact column and a measured column and they are produced by code that shares nothing: one is a linear solve on population covariances, the other is a real OLS fit with an intercept on 40,000 simulated rows. Agreement to Monte-Carlo precision is the check; the closed form is what the prose is allowed to claim.

6. Four repairs behind one interface

naive        β̂                     needs nothing        → biased by (λ−1)β
oracle MoM   β̂/λ                   needs λ              → unbiased, interval scales
replicate    β̂/λ̂,  λ̂ = corr(w₁,w₂)  needs a 2nd reading  → delta-method SE
2SLS         Cov(w₂,y)/Cov(w₂,w₁)      needs a 2nd reading  → standard IV SE

The replicate design is generated forwards from the structural parameters rather than reconstructed from the shared arrays, because it is a different experiment: two readings per row is data the single-measurement design does not have. The page asserts that its (w₁, y) margin still matches the observed law — the extra column is new information, not a different world.

7. What the tests pin

assert(worldA.obs === worldB.obs);                    // same object
assert(|x + u − w| < 1e-13) for every λ on a grid;
assert(Cov(x,u) = Cov(x,ε) = Cov(u,ε) = 0 in the population);
assert(Var(x)=λ, Var(u)=1−λ, Var(ε)=v−c²/λ);
assert(a₃² ≥ 0  ⇔  λ ≥ R²  ⇔  σ²ₕ ≥ 0);
assert(β(λmin) === v/c === 1/(reverse-regression slope));
assert(classical(λ=1) and berkson(θ=0) agree exactly);
assert(Cov(w,u)=σ²ₖ classical, = 0 Berkson; Cov(x,u) the other way round);
assert(every diagnostic is identical across worlds);
assert(β̂₂ closed form === the 2x2 solve to 1e-12);
assert(β̂₂ ≠ β₂ when ρ≠0, === β₂ when ρ=0);
assert(corr(w₁,w₂) → λ);
assert(coverage falls as n rises);
