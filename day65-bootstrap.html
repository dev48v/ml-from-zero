🥾 The bootstrap — resample your data with replacement, recompute the statistic, and read the confidence interval off the resulting distribution. No formula, no normality assumption, and it works for statistics that have no closed form at all. It is the single most useful trick in applied statistics and it is routinely sold as assumption-free, which it is not. This page runs the real thing — percentile, basic (reverse-percentile) and BCa intervals — and then does the only test that matters: measured coverage. A nominal 95% interval is checked against known truth over thousands of simulated datasets, and the number that comes back is often not 95%. For the mean it is close. For the variance at n=10 it is not. For the maximum it collapses entirely, and no number of bootstrap resamples fixes it, because the failure is structural rather than statistical. BCa's bias correction and acceleration are implemented properly (jackknife acceleration, not a hand-wave) and repair the skew cases the percentile interval gets wrong. Resample your own data and pretend it is the population

You have one sample of size n and you want a confidence interval for something with no convenient formula — a median, a 90th percentile, an AUC, the ratio of two things. Classical statistics offers you an asymptotic approximation and a table of conditions.

Efron's answer in 1979 was to stop deriving and start resampling. Draw n values from your own sample with replacement, recompute the statistic, repeat a few thousand times, and read the interval off the spread of the results.

for b in 1..B:
    resample = n draws WITH REPLACEMENT from the sample
    theta*[b] = statistic(resample)

CI = [ quantile(theta*, 0.025), quantile(theta*, 0.975) ]

Four lines. It works for statistics nobody has derived a variance for. It is the best value-for-effort idea in the whole subject.

And it is not assumption-free

The bootstrap assumes your sample is a good stand-in for the population. When that holds badly, the interval is wrong — and it is wrong quietly, because it still produces two numbers with a reassuring 95% attached.

So the only honest way to present it is measured coverage: generate thousands of datasets from a population you know, build the interval each time, and count how often it actually contains the truth. A nominal 95% interval that covers 87% of the time is not a 95% interval.

Three intervals, and they are not the same

  • Percentile. Take the 2.5th and 97.5th percentiles of the bootstrap distribution. Obvious and most common.
  • Basic (reverse percentile). Reflect around the observed estimate: [2θ̂ − q₉₇.₅, 2θ̂ − q₂.₅]. Counter-intuitive, and correct more often than percentile when the estimator is biased — because the bootstrap distribution's skew points the same way as the estimator's, so you have to flip it.
  • BCa. Bias-corrected and accelerated: shifts the quantiles using a bias term z₀ measured from the bootstrap distribution and an acceleration term a from the jackknife. More work, and the only one that adapts to skew.

The failure that is not fixable

The bootstrap does not work for the maximum, and this is not a small-sample wobble. A resample is drawn from the observed values, so max(resample) ≤ max(sample) — always. The bootstrap distribution of the maximum is pinned at the sample max from above, roughly 63% of resamples hit it exactly, and the interval cannot reach the true population maximum, which is larger. Coverage collapses and stays collapsed at any B and any n.

The general lesson is worth more than the special case: the bootstrap works when the statistic is a smooth function of the data. Extremes are not smooth — one observation determines the answer — and the same warning applies to anything dominated by a single point.

B is not the accuracy dial

Two different errors get conflated constantly:

  1. Monte Carlo error — you only drew B resamples. Fixed by raising B.
  2. Bootstrap approximation error — your sample is not the population. Fixed only by more data.

Raising B from 2,000 to 20,000 stabilises the endpoints and changes coverage by nothing worth measuring. The page shows both columns so the distinction is visible rather than asserted. B ≈ 2,000 is enough for a 95% interval; spend the rest of your compute on getting a bigger sample.

When to reach for it

  • Smooth statistics — means, ratios, correlations, model metrics — yes, and BCa if the distribution looks skewed.
  • Extremes, minima, maxima, anything determined by one observation — no.
  • Dependent data — not the ordinary bootstrap. Resampling rows destroys the dependence structure; use a block bootstrap for time series or a cluster bootstrap for grouped data.
  • Tiny samples — check coverage before you trust it. At n=10 several of these intervals are well below their nominal level, which this page measures rather than warns about.

🔨 How it is built

1. The resample, and the detail that matters

function resample(sample, rnd){
  const out = new Array(sample.length);
  for (let i = 0; i < sample.length; i++)
    out[i] = sample[Math.floor(rnd() * sample.length)];   // WITH replacement, same n
  return out;
}

Same size, with replacement. Both halves are load-bearing: a smaller resample changes the variance you are estimating, and sampling without replacement returns the original sample permuted, whose statistic never moves.

2. Percentile and basic are not variations on each other

const lo = quantile(boot, alpha / 2), hi = quantile(boot, 1 - alpha / 2);

percentile = [lo, hi];
basic      = [2 * theta - hi, 2 * theta - lo];   // reflected, and the ends SWAP

The swap is the whole idea. If the bootstrap distribution leans right, the estimator probably does too, so the correction must lean left. Copying the ends across without swapping produces an interval that is sometimes inverted, which is the standard bug here.

3. BCa, with a real jackknife

// bias correction: where does the observed estimate sit in the bootstrap distribution?
const z0 = probit(fraction(boot, b => b < theta));

// acceleration: skew of the jackknife (leave-one-out) values
const jack = sample.map((_, i) => statistic(without(sample, i)));
const jbar = mean(jack), d = jack.map(v => jbar - v);
const a = sum(d³) / (6 * sum(d²)^1.5);

const adj = z => normalCdf(z0 + (z0 + z) / (1 - a * (z0 + z)));
BCa = [ quantile(boot, adj(-1.96)), quantile(boot, adj(+1.96)) ];

Both corrections are measured from the data. z₀ is zero when the observed estimate sits exactly at the bootstrap median, and a is zero when the jackknife values are symmetric — so on symmetric problems BCa reduces to the percentile interval, which is the identity the tests check first. A BCa that differs from percentile on a symmetric problem has a bug in one of the two corrections.

4. Coverage is the only real test

let covered = 0;
for (let t = 0; t < TRIALS; t++){
  const sample = drawFrom(population, n);      // truth is KNOWN
  const ci = bootstrapCI(sample, statistic, B);
  if (ci.lo <= truth && truth <= ci.hi) covered++;
}
coverage = covered / TRIALS;                   // should be 0.95. Often is not.

Everything else on the page is machinery; this loop is the argument. It also records which side the misses fall on, because a 90% interval that misses 9% low and 1% high is a differently broken thing from one that misses 5% each way.

5. The maximum, and why B cannot save it

// a resample is drawn from the observed values, so:
assert(Math.max(...resample) <= Math.max(...sample));    // ALWAYS

// therefore the whole bootstrap distribution of the max is bounded above by the sample max,
// while the truth is above it. The upper end cannot get there.
assert(Math.max(...boot) === Math.max(...sample));

That second assertion holds for every dataset, which is what makes this a structural failure rather than a noisy one. Roughly 1 − (1 − 1/n)n ≈ 63% of resamples contain the sample maximum at all, so the bootstrap distribution has a point mass of about 63% sitting on the ceiling.

6. The tests

assert(coverage(mean, normal, n=100)  > 0.93);   // it works where it works
assert(coverage(max,  anything)       < 0.60);   // and fails where it fails
assert(bootMax === sampleMax);                   // structurally, on every dataset
assert(|BCa − percentile| < tol) on a symmetric problem;
assert(coverage at B=500 ≈ coverage at B=5000);  // B is not the accuracy dial

The second assertion is the one worth stealing. Asserting that a method fails where it should fail is how you find out that your implementation is doing the thing you think it is, rather than something that merely produces plausible numbers.
