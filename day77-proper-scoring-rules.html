All four were about a number somebody reports. This one is about the number somebody sorts on: the leaderboard column that picks which model ships. Nothing here is sampled either. A world is 9 score bins with rational masses, put on one common denominator, so every confusion matrix is a pair of BigInt sums and every comparison is a cross-multiplication rather than a tolerance. Start with the rules. “Brier is proper” is settled here by the sign of an exact rational derivative, not by a search; absolute error is settled the same way and its optimum is a corner, never the truth; and the two metrics everybody actually reports are not scoring rules at all, so the question has to be replaced with: which reports does this number fail to tell apart? On a 241-value grid that answer is exactly one point for Brier, exactly 5.29×1018 for F1 at a 0.5 cut, and exactly C(N+1, m) = 6.50×1015 for AUC. 🔴 Then the fixed point. Search all 512 decision rules, not the m+1 thresholds, and the F1-optimal rule is a threshold on η whose cut is exactly half the F1 it achieves — 0.2696, never 0.5. So the model that tops an F1@0.5 leaderboard is the one that over-states every probability by exactly 0.4607 = 1−F1*, and both what that buys (0.2253 of F1) and what it costs (0.055005 of Brier, and an ECE of 0.2283) are closed forms confirmed against the enumeration. 🔴 And the leaderboard itself. The exactly-correct model is first on Brier, first on log loss, first on AUC and first on accuracy, and 5th of 10 on F1@0.5 — beaten by the lie, by “flag every row” (0.4327), and by a model that is exactly backwards, AUC 0.2629, scoring 0.3688 against the truth’s 0.3140. Over 246 enumerated worlds the truth is first on Brier 246 times and first on F1@0.5 1 time; flagging everything beats it 193 times and the backwards model beats it 144 times. 🔴 The repair works and takes something with it: tune the cut and the lie is worth exactly zero, and 5 models that differ by 0.055 in Brier become bit-identical. 🔴 And the column I built to rank the metrics by how much they can see ranks them backwards: AUC’s indistinguishable set is 814× smaller than F1@0.5’s, and yet AUC ties 5 of the models on the board where F1@0.5 ties 1 — in 245 of 246 worlds. Pure vanilla JavaScript, one file, no build step.

There is no dataset and no generator on this page. A world is a list of score bins; bin i carries an integer mass and a rational conditional probability ηi, and both are folded into two integer vectors on one common denominator, so a confusion matrix is a pair of BigInt subset sums and “model A beats model B” is an integer cross-multiplication. Optima are found by exhausting all 2m decision rules, never by scanning thresholds, so “the optimum is a threshold rule” is a result. Where a closed form exists the enumeration is run anyway and the two are required to be equal as integers. The one number here that is not rational is log loss; its properness still is, because the derivative of the expected loss is (r−η)/(r(1−r)).

0 · the world

 

1 · proper, improper, or not a scoring rule at all

A scoring rule takes one outcome and one reported probability and returns a number. It is proper when reporting the truth is optimal in expectation, and strictly proper when nothing else is. For Brier and log loss the expected score has a derivative that is a rational function of r with exactly one sign change, at η — so properness is decided, not searched. The grid search is run anyway, over every bin, and must agree.

 

2 · properness, rewritten as a price

Forbidding a lie is less useful than pricing one. Expand the Brier score of any report and the cross terms cancel against the truth’s, leaving an identity that holds for every report, honest or not: Brier(r) = Brier(η) + ∑i wi(ri−ηi)². Over rationals that is exact. In doubles it is not, and the residual is printed next to it.

 

3 · what each metric cannot tell apart

F1 and AUC are not scoring rules — they do not decompose over observations at all, so “is it proper” is not a question they can be asked. The question that survives is: given the best possible value of this metric, how many different reports achieve it? Count them on the grid of all (N+1)m reports. Every count below has a closed form; every closed form is checked against a brute-force enumeration of the whole cube at small m.

in-page checks

The number you sort on is an objective

A model outputs probabilities. A leaderboard outputs one number per model. Somewhere between those two things a decision gets made about which model is better, and the usual assumption is that the number is a measurement — that a better model scores higher and the metric is a passive instrument. It is not. A metric is an objective function over reports, and an objective function has an argmax, and there is no law saying that argmax is the truth.

This page builds worlds small enough to check that claim completely. A world is a handful of score bins. Bin i holds a rational share of the data and a rational conditional probability ηi = P(y=1 | bin i). That is the entire specification: no samples, no seeds, no noise. Every confusion matrix, every metric, and every optimum below is a finite exact computation over that specification.

1. Proper is a statement about a derivative

Fix one bin with truth η and report r. The expected Brier score is η(1−r)² + (1−η)r², whose derivative is 2(r−η): negative below η, positive above, zero once. The expected log loss is −η ln r − (1−η)ln(1−r), whose derivative is (r−η)/(r(1−r)): the denominator is positive on the open interval, so the sign is the sign of r−η, and again there is one zero. Both derivatives are rational functions, so the whole argument is an integer comparison and the page runs it at every grid point of every bin. Strict properness is not measured here; it is decided, and then the grid search is run anyway as a second route.

Absolute error is the instructive failure. Its expected value is η + r(1−2η), which is linear in r. A linear function on an interval is minimised at an endpoint, so the optimal report is 1 when η > ½ and 0 when η < ½ — never the truth, unless the truth already is 0 or 1. Mean absolute error on probabilities does not measure how close your probabilities are; it asks you to round them.

Zero–one loss at a cut is the other failure, and a different one. Its expected value is a step function of r, so its optimum is not a wrong point but an interval: every report on the correct side of the cut ties. Accuracy cannot be wrong about the truth, and it cannot recognise it either.

2. F1 and AUC are not scoring rules

Both of the metrics that dominate real leaderboards fall outside the frame entirely. A scoring rule is a function of one outcome and one report, summed over the data. F1 is a ratio of sums; you cannot write it as an average of per-row scores, and its value for one row is not even defined. AUC is a function of pairs. Neither has an expected per-observation score, so neither can be proper or improper — the vocabulary does not apply.

What does apply is the identified set: the set of reports that achieve the metric's best attainable value on this world. For a strictly proper rule that set is a single point, and the point is the truth. For everything else it has positive volume, and the page counts it exactly. On a grid of N+1 values per bin: Brier admits exactly one report; accuracy and F1 at a fixed cut admit (N/2)|S|(N/2+1)m−|S|, which is one part in 2m of the cube in the limit, because only the side of the cut matters; and AUC admits exactly C(N+1, m), one part in m!, because only the order matters and each choice of m distinct grid values can be arranged in the winning order exactly one way. All three closed forms are checked against a brute-force enumeration of the entire cube at small m, where the whole thing fits in memory.

3. The F1 threshold is half the F1

Write F1 in terms of a decision rule d: F1 = 2 E[ηd] / (E[d] + π). That is linear-fractional in d, and a linear-fractional program has a clean optimum. If the best achievable value is F, then 2E[ηd] = F(E[d]+π) at the optimum, so maximising F1 is the same as maximising E[(2η − F)d], which flags a bin exactly when η > F/2.

Two things fall out. The optimal rule is a threshold on η — not assumed, derived, and here also confirmed by exhausting all 2m subsets, so the page never has to take the threshold family on trust. And the threshold is F1*/2, which is at most ½ and equals ½ only when the model is perfect. The default cut of 0.5 is F1-optimal in exactly one case, and it is the case where you did not need a threshold.

Accuracy behaves differently, and the contrast is the whole point. Maximising E[ηd] + E[(1−η)(1−d)] flags a bin exactly when η > ½. Accuracy's optimal cut is 0.5. So a truthful model thresholded at 0.5 is doing the accuracy-optimal thing, and something else entirely as far as F1 is concerned. That mismatch is not a subtlety at the margin: it is the entire effect on this page.

4. What the lie costs, and what it buys

If the F1-optimal cut is F1*/2 and the leaderboard insists on 0.5, then the way to top the leaderboard is to move your reports until the two cuts coincide. Apply r = (η+s)/(1+s), which is strictly increasing and therefore does not change the model's ranking at all. It crosses 0.5 exactly where η crosses (1−s)/2, so s = 1 − F1* makes the 0.5 cut do precisely what the F1-optimal rule does, and the model hits the ceiling.

Both sides of that trade are closed forms. Every report moves up by s(1−η)/(1+s), so the expected calibration error is exactly s(1−π)/(1+s), and by the excess identity the Brier cost is exactly s²/(1+s)² · E[(1−η)²]. The page derives both and then confirms them against the enumeration as exact rationals.

It also prices the cheapest lie. You do not have to over-state everything; only the bins sitting between F1*/2 and 0.5 need to move, and only as far as 0.5. That infimum is an order of magnitude smaller than the uniform over-statement — and it is an infimum, not a minimum, because a report of exactly 0.5 falls back out of a strict decision set.

5. The controls

Four things a practitioner would reach for instead, each measured on the same world.

Tune the threshold. It works, completely: the lie's advantage drops to exactly zero. It works because the tuned F1 depends only on the upper level sets the report can reach, and a strictly increasing transform reaches the same ones. So after tuning, every monotone model — the truth, the rank-only model that has thrown its probabilities away, the over-confident model, the under-confident model and the liar — scores the same number to the last bit, while their Brier scores still differ. The repair removes the artefact and the signal together.

Report the base rate. The constant forecaster r = π is perfectly calibrated: reliability exactly 0, ECE exactly 0. It is also perfectly useless: resolution exactly 0, AUC exactly ½. Its Brier is exactly π(1−π), and it sits above the truth's by exactly Var(η). Note what it does not do: it does not top the F1 board, it scores exactly zero there, because a constant below 0.5 flags nothing at a 0.5 cut. The useless model that does score well is the same model with the cut moved.

Flag every row. That is the one. It reads nothing, learns nothing, and scores 2π/(1+π) exactly — and on most of the worlds in the sweep that is a higher F1 than the exactly-correct model gets at the default cut.

Check calibration. ECE cannot separate the truth from the base rate: both are exactly zero. Worse, "perfectly calibrated" is not one model. Partition the bins any way you like and report each group's own rate; every one of those reports has ECE exactly zero. The page enumerates all of them — every set partition, Bell(m) of them — and reads off the Brier they span. The interval runs from the truth's Brier to the base rate's, and its width is exactly Var(η).

6. The thing I got wrong

The identified-set counts were meant to be the ranking column: the smaller a metric's indistinguishable set, the more it can see. AUC's set is hundreds of times smaller than F1@0.5's, so AUC should be the more discriminating metric. On the actual leaderboard the opposite happens, in nearly every world in the sweep: AUC ties most of the roster at the top and F1@0.5 ties almost none of it.

Both facts are correct and the inference between them was not. Volume measures how much of the whole cube of conceivable reports a metric collapses. A roster of real models does not live in that cube — it lives on the monotone family, models that agree about the ordering and disagree about the numbers, which is exactly what recalibration, temperature scaling and a different loss function produce. AUC's tiny set is aimed straight at that family, so it swallows the whole roster. F1@0.5's enormous set is spread over reports nobody would ever produce. A metric's blind spot is only a problem where your candidates are, and the volume of the blind spot does not tell you that.

Two smaller corrections, both kept. The brute-force worlds originally placed η off the grid, so "the Brier optimum is exactly one point" was true while "and that point is the truth" was not something the enumeration could check; the worlds are now built on the grid and the identity of the point is verified. And accuracy at 0.5 does not misbehave at all: it ranks the truth first in every world in the sweep. "Improper metrics mislead you" is too broad. The damage is specific and it is arithmetic — it comes from evaluating at a cut that is not the cut your metric wanted.

7. What to take away

Sorting by a strictly proper rule cannot be gamed by miscalibration, because the excess over the truth is a squared distance and squared distances are non-negative. That is not a preference; it is the identity in section 2. Sorting by F1 at a fixed cut can be gamed, exactly, by an amount you can write down before you see the data. And sorting by anything that only reads the ordering — AUC, or F1 after threshold tuning — is immune to the game and blind to the thing the game was about.

None of which means F1 is a bad metric. It means F1 is a metric about a decision rule, and reporting it against an untuned 0.5 cut compares your model to a decision nobody chose. If the deployed cut is 0.5 because a product decision fixed it there, then F1@0.5 is the right number and the lie is not a lie — it is the correct thing to do, and it should be done in the threshold rather than in the probabilities.

Build it

Everything on this page rests on one representation. Put the world on a common denominator and the entire apparatus becomes integer arithmetic.

// bin i: integer mass wI[i] out of W, truth eta_i = eN[i]/120
//   a[i] = wI[i] * eN[i]           positive mass in bin i, over D = W*120
//   b[i] = wI[i] * (120 - eN[i])   negative mass in bin i, over D
// a decision set S is then just two BigInt sums:
//   TP = A/D   FP = B/D   FN = (Ta-A)/D   TN = (Tb-B)/D
//   F1  = 2A / (A + B + Ta)
//   Acc = (A + Tb - B) / D
// so "model X beats model Y" is  numX * denY > numY * denX,  in BigInt.

Properness needs no search. Differentiate the expected score and look at the sign:

// Brier:    d/dr [ eta(1-r)^2 + (1-eta)r^2 ]      = 2(r - eta)
// log loss: d/dr [ -eta*ln r - (1-eta)ln(1-r) ]   = (r - eta) / (r(1-r))
// both are rational in r, both change sign exactly once, both at eta.
// absolute error: eta + r(1-2eta)  is LINEAR, so the optimum is a corner.
// 0-1 loss at cut c: a step function, so the optimum is an interval.

The optimal decision rule is found by exhausting the power set, so that the threshold family is a conclusion rather than a premise. Subset sums are built incrementally in one pass:

for (let s = 1; s < (1 << m); s++){
  const low = s & (-s), i = 31 - Math.clz32(low), rest = s ^ low;
  A[s] = A[rest] + a[i];  B[s] = B[rest] + b[i];
}
// then argmax over all 2^m of  2A / (A + B + Ta)
// and check:  optimal set === { i : eta_i > F1*/2 }

The identified sets are closed forms, each verified against a full enumeration of the cube at small m:

Brier          exactly 1 point                       (and it is eta itself)
accuracy@0.5   (N/2)^|S| * (N/2+1)^(m-|S|)           -> 2^-m of the cube
F1@0.5         (N/2)^|S| * (N/2+1)^(m-|S|)           -> 2^-m of the cube
AUC            C(N+1, m)                             -> 1/m! of the cube

The lie is constructive, not searched for:

// (eta + s)/(1 + s) > 1/2   <=>   eta > (1 - s)/2
// so s = 1 - F1*  puts the 0.5 cut exactly on the F1-optimal threshold.
// price  = s^2/(1+s)^2 * E[(1-eta)^2]     (Brier, by the excess identity)
// ECE    = s(1-pi)/(1+s)
// gain   = F1* - F1(eta > 1/2)
// and at a TUNED cut the gain is exactly 0, because the map is monotone.

The calibrated set is every set partition of the bins. Enumerating Bell(m) of them naively and scoring each with rational Brier took four seconds at m=9 and twenty-four at m=10. Cancelling the algebra first turns it into small-integer work: the excess of a partition report over the truth is the within-group variance of η, and after expansion the only partition-dependent term is ∑g Sg²/Wg.

excess(partition) = ( T_tot - sum_g S_g^2 / W_g ) / (W * 120^2)
  S_g = sum of wI*eN over the group,  W_g = sum of wI over the group
// maximised by the singleton partition (excess 0 -> the truth)
// minimised by the single group        (excess Var(eta) -> the base rate)
