🎯 Multiple comparisons — yesterday's page showed one experiment checked many times. This is the other shape of the same problem: many experiments checked once. Track 40 metrics on an A/B test where nothing changed and you will find a "significant" one about 87% of the time, because 1 − 0.95⁴⁰ is 0.87 — and that number is measured here, not quoted. The fix everyone reaches for is Bonferroni, which controls the probability of any false positive (FWER) and is correct, conservative, and often useless: at 40 metrics each test runs at α = 0.00125 and real effects vanish. Benjamini–Hochberg controls something different — the expected proportion of your discoveries that are false (FDR) — which is usually the quantity you actually care about when screening. The distinction is not a technicality: at 200 hypotheses with 20 real effects, Bonferroni finds a handful and BH finds most of them, while keeping the false-discovery share near the level you set. Every rate on this page is counted over simulated experiments whose ground truth is known.

With 0 real effects every rejection is a false positive, and the first card below is the number that should alarm you.

THE BH STAIRCASE, ON ONE EXPERIMENT

Sorted p-values against the line i·α/m. BH finds the largest i whose p-value is under the line and rejects everything up to it — including p-values that individually sit above it. That "reject things that failed their own threshold" step is the part that looks wrong and is the whole method.

Two different questions, two different guarantees


      
Yesterday: one experiment, looked at repeatedly. Today: many experiments, each looked at
      once. Same underlying failure — more chances to be surprised — but the fixes control
      genuinely different quantities, and choosing the wrong one is expensive in both directions.


      

        
FWER — P(at least one false positive anywhere). Suits a
        confirmatory test where a single wrong claim is unacceptable.

        
FDR — E[false discoveries / total discoveries]. Suits
        screening, where you expect to follow up and a known minority of duds is tolerable.

      


      
Why 40 metrics is 87%

      
Each test is independently wrong 5% of the time under the null. The chance that
      none of 40 is wrong is 0.95⁴⁰ ≈ 0.13, so the chance at least one is wrong is
      ≈ 87%. That is not a subtle statistical effect — it is near-certainty, and it
      is why "we tracked 40 metrics and one moved" is not evidence of anything.


      
Bonferroni: correct, and often too blunt

      
Test each hypothesis at α/m. The union bound guarantees FWER ≤ α, and it needs no assumption
      about dependence, which is why it survives everything. The cost is power: at m = 40 each test
      runs at α = 0.00125, and a real effect that would have been found comfortably at 0.05 now
      disappears. The simulation shows exactly how many real effects are lost.


      
Holm: strictly better, and free

      

        
Holm's step-down gives the same FWER guarantee with
        uniformly more power — it is never worse than Bonferroni and often better,
        under identical assumptions. There is essentially no reason to use plain Bonferroni once you
        know Holm exists, and yet Bonferroni is what everyone reaches for.

      


      
Benjamini–Hochberg, and the step that looks wrong

      
Sort the p-values. Find the largest k with p(k) ≤ k·α/m. Reject
      all hypotheses 1…k — including ones whose own p-value exceeds their own
      threshold.

      
That step feels like cheating and is not. The guarantee is about the proportion of
      discoveries that are false, not about each one individually, and rejecting the whole prefix is
      what makes the proportion come out right. The staircase plot on the SIMULATE tab shows it
      happening.


      
FDR is only meaningful if you discover something

      
Under a complete null — no real effects at all — FDR and FWER coincide, because any
      discovery is a false one. BH's advantage appears exactly when some effects are real, which is
      also when the "0 real effects" slider stops being the interesting setting.

      
And a method that rejects nothing reports an FDR of 0. Always read the discovery count
      alongside it, which is why both columns are in the table.


      
Dependence

      
Plain BH assumes independence or positive dependence. Metrics on the same experiment are
      usually positively correlated — revenue and conversion move together — so BH is normally fine.
      Under arbitrary dependence you need Benjamini–Yekutieli, which divides by a
      harmonic factor and costs real power. Knowing which regime you are in matters more than the
      arithmetic.


      
The honest summary

      
One confirmatory metric decided in advance: no correction needed. A handful of pre-registered
      metrics where a wrong claim is costly: Holm. Screening hundreds of metrics or features to decide
      what to investigate: BH. Reporting the raw p-values from 40 metrics and highlighting the small
      one: not statistics.


    

  






  

    


      
🔨 Build it yourself


      
1. Generate p-values whose truth you know

      
// nulls: p ~ Uniform(0,1) exactly. alternatives: a shifted z, converted to p.
function experiment(rng, m, nReal, effect){
  const ps = [], isReal = [];
  for (let i = 0; i < m; i++){
    if (i < nReal){
      const z = effect + gauss(rng);
      ps.push(2 * (1 - normCdf(Math.abs(z))));
      isReal.push(true);
    } else {
      ps.push(rng());              // the null p-value IS uniform - that is the definition
      isReal.push(false);
    }
  }
  return { ps, isReal };
}

      
Drawing null p-values as uniform is not a shortcut; it is what "p-value under the null"
      means. If your simulation needs a test statistic to produce them, the test is what you are
      studying — here the corrections are.


      
2. The three corrections

      
const uncorrected = (ps, a) => ps.map(p => p <= a);

const bonferroni  = (ps, a) => ps.map(p => p <= a / ps.length);

function holm(ps, a){
  const m = ps.length;
  const order = ps.map((p, i) => [p, i]).sort((x, y) => x[0] - y[0]);
  const out = new Array(m).fill(false);
  for (let k = 0; k < m; k++){
    if (order[k][0] > a / (m - k)) break;   // step DOWN, stop at the first failure
    out[order[k][1]] = true;
  }
  return out;
}

function benjaminiHochberg(ps, a){
  const m = ps.length;
  const order = ps.map((p, i) => [p, i]).sort((x, y) => x[0] - y[0]);
  let kMax = -1;
  for (let k = 0; k < m; k++)
    if (order[k][0] <= (k + 1) * a / m) kMax = k;   // the LARGEST such k
  const out = new Array(m).fill(false);
  for (let k = 0; k <= kMax; k++) out[order[k][1]] = true;  // reject the whole prefix
  return out;
}

      
Note the difference in the loops. Holm breaks at the first failure; BH keeps
      scanning and remembers the last success. Writing BH with a break is the classic
      bug — it silently turns BH into something weaker and the FDR control quietly stops being what
      you think.


      
3. Measure the two guarantees separately

      
let anyFalse = 0, fdrSum = 0, found = 0, realTotal = 0, discoveries = 0;
for (const trial of trials){
  const rej = method(trial.ps, alpha);
  const V = rej.filter((r, i) => r && !trial.isReal[i]).length;   // false discoveries
  const S = rej.filter((r, i) => r &&  trial.isReal[i]).length;   // true discoveries
  if (V > 0) anyFalse++;                                          // -> FWER
  fdrSum += (V + S) ? V / (V + S) : 0;                            // -> FDR
  found += S; realTotal += trial.isReal.filter(Boolean).length;
  discoveries += V + S;
}
const FWER = anyFalse / trials.length;
const FDR  = fdrSum   / trials.length;      // EXPECTED PROPORTION, averaged per trial
const power = realTotal ? found / realTotal : 0;

      
FDR is an average of ratios, one per experiment, with 0 when nothing is discovered. Pooling
      all discoveries across trials and dividing once gives a different number that is not FDR.


      
4. Check the null against theory first

      
// with nReal = 0, the uncorrected FWER must land on 1 - (1-alpha)^m

5. Then check the guarantees hold

      
assert(fwer(bonferroni) <= alpha + tol);       // union bound
assert(fwer(holm)       <= alpha + tol);       // same guarantee
assert(power(holm)      >= power(bonferroni)); // uniformly more power
assert(fdr(bh)          <= alpha + tol);       // FDR, not FWER
assert(power(bh)        >= power(holm));       // the trade BH is making
