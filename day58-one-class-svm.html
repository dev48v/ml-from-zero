MachineLearningFromZero · Day 58

🛡️ The One-Class SVM — novelty detection that stops describing the normal data and instead wraps a boundary around it, then flags anything outside as anomaly. Every anomaly detector so far answered the question with a summary of the bulk: the Elliptic Envelope (D56) fits one Gaussian ellipse, the Local Outlier Factor (D57) compares each point's local density to its neighbours', the Isolation Forest (D26) counts how few random cuts isolate a point. The One-Class SVM takes the Support Vector Machine (D12) idea — a max-margin frontier — and turns it inward: with only "normal" examples and no anomalies to learn from, it learns the support of the data, a curved frontier that hugs the inliers as tightly as it can while allowing a controlled fraction to spill outside. Concretely (Schölkopf's formulation) it maps points through an RBF kernel K(x,y)=exp(−γ‖x−y‖²) — the kernel trick (D42), so the feature map φ is never built — and separates the data from the origin with maximum margin ρ, solving the dual min ½ Σᵢⱼ αᵢαⱼ K(xᵢ,xⱼ) subject to Σαᵢ = 1 and the box 0 ≤ αᵢ ≤ 1/(νn). The points that end up with αᵢ > 0 are the support vectors — the only ones that shape the frontier — and the offset ρ is read off the ones sitting exactly on it. The decision function f(x) = Σᵢ αᵢ K(x,xᵢ) − ρ then paints the whole plane: f(x) ≥ 0 is inside — normal, f(x) < 0 is outside — anomaly, and the decision boundary is the contour f = 0. Two knobs govern everything: ν is a beautiful hyperparameter with a hard guarantee — it is simultaneously an upper bound on the fraction of outliers and a lower bound on the fraction of support vectors — and γ sets the RBF width, so raising it tightens the frontier and makes it wigglier, lowering it smooths it toward a single round blob. Everything below runs live in your browser: click to scatter normal data, watch a hand-rolled kernel model fit the boundary and light up the support vectors, slide ν and γ to feel the frontier breathe, pit the kernel boundary against a single Gaussian ellipse on a ring and two blobs it physically cannot wrap, and read the decision function as a landscape of summed kernel bumps. It is the kernel-boundary, shape-flexible member of the anomaly-detection family — the one that learns a frontier rather than a density or a distance. (Honest note: the maths above — the dual QP for a sparse α, support vectors, the ν-property — is real libsvm one-class SVM. The live demo implements the same decision-function form f(x)=Σαᵢk(x,xᵢ)−ρ as an SVDD / kernel-density model with uniform weights αᵢ=1/n and a ν-quantile offset ρ — a faithful didactic approximation of libsvm's SMO, tuned so ν and γ behave exactly as they should, robust and transparent rather than the exact sparse solve.)

Learn a boundary around "normal", flag whatever falls outside. 🔨 Build it yourself

    
A One-Class SVM is a kernel, a decision function of the form f(x)=Σᵢαᵢk(x,xᵢ)−ρ, and an offset. Below is the runnable core the LOOK tab actually uses — the RBF kernel, the SVDD / kernel-density score that realizes that decision function with the transparent uniform weight αᵢ=1/n, the ν-quantile offset ρ, the support-vector test, the decision function itself, and the marching-squares routine that turns f=0 into a drawn boundary. It is a faithful didactic approximation: production libsvm solves a sparse dual QP with SMO for non-uniform αᵢ (the maths is in UNDERSTAND); this version keeps the identical decision-function form but uses uniform weights + a quantile offset so ν and γ behave exactly as the textbook says and every kernel contribution is visible — robust and readable on a few hundred points.

    
    
      
  1. 
        
    1
    The RBF kernel and the kernel matrix
    
        
    Everything touches the data only through the RBF (Gaussian) kernel K(x,y)=exp(−γ‖x−y‖²) — the kernel trick (D42), so the infinite-dimensional feature map is never built. γ is the width: large γ ⇒ each point's influence decays fast ⇒ a wiggly, local frontier; small γ ⇒ broad influence ⇒ one smooth dome. The n×n matrix Kᵢⱼ is all the solver ever sees.
    
        
    // RBF kernel in normalised [0,1] coordinates
function rbf(a, b, g) {
  const dx = a.x - b.x, dy = a.y - b.y;
  return Math.exp(-g * (dx * dx + dy * dy));   // 1 when identical → 0 when far
}
// full kernel matrix K[i][j] = rbf(x_i, x_j, gamma)
function kernelMatrix(pts, gamma) {
  const n = pts.length, K = [];
  for (let i = 0; i < n; i++) {
    const row = new Float64Array(n);
    for (let j = 0; j < n; j++) row[j] = rbf(pts[i], pts[j], gamma);
    K.push(row);
  }
  return K;
}
    
      
    2. 
      
  2. 
        
    2
    The SVDD / kernel-density score
    
        
    The decision function is f(x)=Σⱼ αⱼ K(x,xⱼ) − ρ. libsvm's SMO finds a sparse set of weights αⱼ by solving the dual QP min ½αᵀKα s.t. Σα=1, 0≤α≤1/(νn) (see UNDERSTAND). Here we take the transparent SVDD / Parzen choice αⱼ = 1/n, so the raw score of a point is simply its RBF kernel density sᵢ = (1/n) Σⱼ K(xᵢ,xⱼ) — high in the crowded core, low out on the fringe. Same decision-function form, every point contributing visibly.
    
        
    // SVDD / Parzen score of each point = its RBF kernel density
//   s_i = (1/n) * sum_j K(x_i, x_j)      (uniform weight alpha_j = 1/n)
// high  -> crowded / normal region      low -> isolated / candidate anomaly
function densityScores(pts, gamma) {
  const n = pts.length, s = new Float64Array(n);
  for (let i = 0; i < n; i++) {
    let acc = 0;
    for (let j = 0; j < n; j++) acc += rbf(pts[i], pts[j], gamma);
    s[i] = acc / n;
  }
  return s;
}
// (libsvm instead learns a SPARSE alpha via SMO on the dual — same f(x) form)
    
      
    3. 
      
  3. 
        
    3
    The ν-quantile offset ρ — the ν guarantee
    
        
    Now place the offset ρ. The ν-property says a ν-fraction of points end up outside the boundary, so we set ρ to the ν-quantile of the scores: exactly ⌊ν·n⌋ points fall strictly below it and are flagged. This realizes the property directly, is perfectly monotone in ν, and (unlike reading ρ off a near-flat SMO margin on smooth data) gives a crisp, high-contrast boundary. In the exact SMO solution this same ρ is the common score of the margin support vectors.
    
        
    // rho = the nu-quantile of the scores  ->  floor(nu*n) points fall outside
function chooseRho(scores, nu) {
  const sorted = Array.from(scores).sort((a, b) => a - b);   // ascending
  const kOut = Math.min(sorted.length - 1, Math.floor(nu * sorted.length));
  return sorted[kOut];               // exactly kOut points score below rho
}
// nu is an UPPER bound on the flagged (outlier) fraction here, by construction,
// and a LOWER bound on the support-vector fraction (next step) — the nu-property.
    
      
    4. 
      
  4. 
        
    4
    The support vectors — the frontier points
    
        
    In a one-class SVM the support vectors are the points that touch or cross the boundary — the ones that pin where ρ sits; deep-interior points (with αᵢ=0 in the sparse solve) are irrelevant. With the quantile offset that set is simply the lowest-scoring points: everything strictly below ρ (the flagged margin errors) plus a thin band just above it (points sitting on the frontier). Their count is ≥ ν·n, the other half of the ν-property.
    
        
    // support vectors = points on or outside the frontier (lowest scores)
function supportVectors(scores, nu, bandFrac = 0.12) {
  const n = scores.length;
  const order = [...scores.keys()].sort((a, b) => scores[a] - scores[b]); // asc
  const kOut = Math.floor(nu * n);                     // strictly outside (flagged)
  const kSV  = Math.min(n, kOut + Math.max(1, Math.round(bandFrac * n)));
  const isSV = new Array(n).fill(false);
  for (let r = 0; r < kSV; r++) isSV[order[r]] = true; // the kSV lowest scores
  return isSV;                                          // |SV| / n  >=  nu
}
    
      
    5. 
      
  5. 
        
    5
    Put it together — fit, then the decision function
    
        
    The fit is just the three pieces: score every point, choose ρ, mark the support vectors. Then the decision function paints the whole plane — and because every point carries the same weight 1/n, it is exactly a thresholded kernel density: f(x) = (1/n) Σⱼ K(x,xⱼ) − ρ, positive inside, negative outside. It is inductive: score any brand-new point the same way (no self-term games, so isolated novelties are caught).
    
        
    function fit(pts, nu, gamma) {
  const scores = densityScores(pts, gamma);   // step 2
  const rho    = chooseRho(scores, nu);        // step 3  (the nu-quantile)
  const isSV   = supportVectors(scores, nu);   // step 4  (frontier points)
  return { pts, gamma, rho, scores, isSV };
}
// signed decision value at ANY point x — every training point drops an equal bump
function decision(x, M) {
  let s = 0; for (const p of M.pts) s += rbf(x, p, M.gamma);
  return s / M.pts.length - M.rho;   // >=0 normal · <0 anomaly (a signed score)
}
// sanity: boundary encloses the dense core; a far point scores < 0;
// raising gamma makes the boundary wigglier; raising nu flags more; never NaN.
    
      
    6. 
      
  6. 
        
    6
    Draw the boundary — marching squares on f=0
    
        
    The boundary is the contour f(x)=0. Evaluate f on a grid, then for every cell look at the sign of its four corners: wherever a sign flips along an edge, linearly interpolate the crossing point and connect them. That is marching squares — a few lines that turn a scalar field into a crisp curve, no library.
    
        
    // draw the f=0 contour from a grid of node values (marching squares)
function drawContour(ctx, vals, nx, ny, x0, y0, sx, sy) {
  const V = (r, c) => vals[r * nx + c];
  ctx.beginPath();
  for (let r = 0; r < ny - 1; r++) for (let c = 0; c < nx - 1; c++) {
    const tl = V(r,c), tr = V(r,c+1), br = V(r+1,c+1), bl = V(r+1,c);
    const X = x0 + c*sx, Y = y0 + r*sy, P = [];
    if ((tl<0)!==(tr<0)) P.push([X + sx*(-tl)/(tr-tl), Y]);            // top
    if ((tr<0)!==(br<0)) P.push([X + sx,               Y + sy*(-tr)/(br-tr)]); // right
    if ((bl<0)!==(br<0)) P.push([X + sx*(-bl)/(br-bl), Y + sy]);      // bottom
    if ((tl<0)!==(bl<0)) P.push([X,                    Y + sy*(-tl)/(bl-tl)]); // left
    if (P.length >= 2) { ctx.moveTo(P[0][0],P[0][1]); ctx.lineTo(P[1][0],P[1][1]); }
  }
  ctx.stroke();
}

    7
    In practice — the standard tool
    
        
    You rarely hand-roll it. scikit-learn wraps libsvm's SMO in OneClassSVM. The knobs are the same two you slid above: nu (the outlier / support-vector bound) and gamma (RBF width). Because it is distance-based, scale your features first, and remember there is no cross-validation target — you tune ν and γ by how the flagged fraction and boundary look, or against a small labelled validation set.
    
        
    # scikit-learn — one-class SVM in three lines
from sklearn.svm import OneClassSVM

oc = OneClassSVM(kernel="rbf", nu=0.1, gamma="scale")
oc.fit(X_train_normal)                 # trained on inliers only
labels = oc.predict(X_new)             # +1 inlier / −1 novelty
scores = oc.decision_function(X_new)   # signed distance to the boundary (f)
# nu ≈ upper bound on outliers & lower bound on support vectors; scale X first

The One-Class SVM is the kernel-boundary corner of anomaly detection: instead of summarising the normal data with a density (Elliptic Envelope D56) or a local-density ratio (LOF D57), it learns a frontier that wraps the support of the data as tightly as ν allows. That RBF flexibility is its superpower — it can carve out a ring, two islands, a crescent — the exact shapes the single ellipse of D56 cannot represent. It reuses the max-margin machinery of the Support Vector Machine (D12) and the kernel trick (D42), and unlike LOF it is naturally inductive: once fit, it scores brand-new points, which is why it is a go-to for genuine novelty detection (train on clean data, flag drift later). Its costs are the flip side of that power: two coupled knobs (ν and γ) with no label to cross-validate against, real sensitivity to feature scaling and to contamination in the training set, and an O(n²)–O(n³) solve that makes it a moderate-n tool, not a millions-of-rows one (that's where Isolation Forest D26 wins).

The One-Class SVM takes the max-margin idea from the SVM (D12), pushes the data through an RBF kernel (D42) K(x,y)=exp(−γ‖x−y‖²), and separates it from the origin with maximum margin — solving the dual min ½αᵀKα s.t. Σα=1, 0≤α≤1/(νn) for the weights that light up the support vectors. The decision function f(x)=ΣαᵢK(x,xᵢ)−ρ then carves the plane at f=0: inside is normal, outside is anomaly. Its two knobs are unusually principled — ν is both an upper bound on the outlier fraction and a lower bound on the support-vector fraction, and γ trades a smooth round frontier for a tight wiggly one. Because it fits a boundary rather than a density or a distance, it wraps non-convex shapes a single Elliptic Envelope (D56) cannot, and unlike the transductive LOF (D57) it scores brand-new points — the natural fit for novelty detection. It joins Isolation Forest (D26), the Elliptic Envelope and LOF as the kernel-boundary member of the outlier-detection toolbox. 👉 When your "normal" region is complex or non-convex and you need to flag unseen novelties, reach for the One-Class SVM — and budget time to tune ν and γ.
