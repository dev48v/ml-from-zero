MachineLearningFromZero · Day 56

🥚 The Elliptic Envelope — outlier detection that draws one ellipse around "normal" and flags whatever falls outside. Its one modelling bet is simple: assume the inliers are drawn from a single Gaussian. Under that assumption every contour of constant density is an ellipse, and "how far out is this point?" has a precise, scale-and-correlation-aware answer — the Mahalanobis distance d²(x) = (x − μ)ᵀ Σ⁻¹ (x − μ), which stretches and rotates ordinary Euclidean distance by the data's own covariance so that one unit means "one standard deviation in that direction." For genuinely Gaussian data those squared distances follow a chi-square law with p degrees of freedom, so a clean statistical cutoff drops out: flag every point whose d² exceeds the χ²ₚ quantile at 1 − contamination — for 2-D that threshold is exactly −2·ln(contamination), and sliding contamination literally grows or shrinks the decision ellipse. The catch, and the whole reason this is a robust-stats method, is estimating μ and Σ: the plain empirical covariance is destroyed by outliers — a single gross point drags the mean toward it and inflates the covariance so much that the point ends up inside its own bloated ellipse (masking). The fix is a robust covariance — a Minimum-Covariance-Determinant-style estimate that iteratively keeps the tight majority of points and refits, so the outlier never gets a vote. Below it all runs live in your browser: a 2-D scatter you click to fill, a hand-rolled mean / covariance / 2×2 inverse / Mahalanobis / 2×2 eigen for the ellipse, plain-vs-robust envelopes that visibly diverge when one outlier is tossed in, a contamination slider resizing the boundary, and the classic distance-distance plot that unmasks the points the plain estimate misses. It belongs to the same robust-stats thread as RANSAC (D51), Huber (D52) and Theil–Sen (D53) — but here the object being made robust is the covariance.

Draw one ellipse around the "normal" cloud, flag everything outside it. Assume the inliers are Gaussian, estimate a center μ and a covariance Σ, and score each point by its Mahalanobis distance d² = (x−μ)ᵀ Σ⁻¹ (x−μ). Those squared distances are χ²-distributed for clean Gaussian data, so the decision boundary is the ellipse d² = χ²-cutoff — and the contamination you expect sets that cutoff. The twist is robustness: a single outlier wrecks the plain covariance, so we fit a robust one that quietly ignores the extremes. 🔨 Build it yourself

    
The Elliptic Envelope is short — the exact routine the LOOK tab runs, no scikit-learn black box. Below is the runnable core: mean and the 2×2 covariance by hand, a jitter-guarded 2×2 inverse and the Mahalanobis distance, the chi-square cutoff that turns a contamination fraction into a decision boundary, a 2×2 symmetric eigen-decomposition to orient and size the decision ellipse, the MCD-style robust covariance (concentration steps that drop the extremes and refit, plus a consistency rescale), and the plain-vs-robust fit that flags every point. Every ellipse and dot the LOOK tab draws comes from these snippets.

    
    
      
  1. 
        
    1
    Mean and the 2×2 covariance — by hand
    
        
    Everything starts with a center μ and a spread Σ. For 2-D points, Σ is a symmetric 2×2: the two variances on the diagonal and one covariance off it. We compute them over a chosen subset of indices (the whole set for the plain estimate, a clean subset for the robust one).
    
        
    // mean + 2x2 covariance over a subset of point indices
function meanCov(pts, idx) {
  const N = idx.length;
  let mx = 0, my = 0;
  for (const i of idx) { mx += pts[i].x; my += pts[i].y; }
  mx /= N; my /= N;                              // the center μ
  let cxx = 0, cyy = 0, cxy = 0;
  for (const i of idx) {
    const dx = pts[i].x - mx, dy = pts[i].y - my;
    cxx += dx*dx; cyy += dy*dy; cxy += dx*dy;    // Σ = [[cxx,cxy],[cxy,cyy]]
  }
  const d = Math.max(1, N - 1);                  // unbiased divisor
  return { mx, my, cxx: cxx/d, cyy: cyy/d, cxy: cxy/d };
}
    
      
    2. 
      
  2. 
        
    2
    The 2×2 inverse (ridge-guarded) and the Mahalanobis distance
    
        
    Mahalanobis distance is the whole scoring function: d²(x) = (x−μ)ᵀ Σ⁻¹ (x−μ). It measures distance in units of standard deviation along each correlated direction, so a point two σ out along a thin axis is as "far" as one two σ out along a fat one. Inverting a 2×2 is a one-liner via the adjugate over the determinant — but a nearly-collinear cloud makes Σ singular, so we add a whisker of ridge to the diagonal and guard the determinant. That is exactly why the LOOK tab never NaNs. Note d²(μ) = 0 by construction.
    
        
    // inverse of a symmetric 2x2 covariance, with a tiny ridge for stability
function inv2(cxx, cyy, cxy) {
  const tr = cxx + cyy;
  const r  = 1e-9 + 1e-7 * tr;          // ridge scales with the data
  const a = cxx + r, c = cyy + r, b = cxy;
  let det = a*c - b*b;
  if (!(Math.abs(det) > 1e-14)) det = (det >= 0 ? 1 : -1) * 1e-14;  // never divide by 0
  return { i00: c/det, i01: -b/det, i11: a/det, det };   // Σ⁻¹ (symmetric)
}
// squared Mahalanobis distance of a centered vector (dx,dy)
function maha2(dx, dy, inv) {
  return inv.i00*dx*dx + 2*inv.i01*dx*dy + inv.i11*dy*dy;   // = 0 at the mean
}
    
      
    3. 
      
  3. 
        
    3
    The chi-square cutoff — contamination becomes a boundary
    
        
    If the inliers really are Gaussian, their squared Mahalanobis distances follow a chi-square law with p degrees of freedom (p = 2 here). So "flag the outer c fraction" becomes "flag d² above the χ²ₚ quantile at 1 − c." For p = 2 the chi-square CDF is the clean F(x) = 1 − e^{−x/2}, so that quantile is just −2·ln(c) — a closed form, no tables. Sliding the contamination directly resizes the ellipse.
    
        
    // χ² cutoff on squared Mahalanobis distance for p = 2 dimensions.
// χ²₂ CDF is F(x) = 1 − e^(−x/2)  ⇒  quantile at prob q is −2·ln(1−q).
// We want the (1−c) quantile, so the cutoff is −2·ln(c).
function chiCut2(contamination) {
  const c = Math.min(0.999, Math.max(1e-4, contamination));
  return -2 * Math.log(c);              // e.g. c=0.10 → 4.605 ; c=0.50 → 1.386
}
// flag = outside the ellipse
function flag(d2, cut) { return d2 > cut; }
    
      
    4. 
      
  4. 
        
    4
    2×2 eigen-decomposition — orient and size the ellipse
    
        
    The decision boundary d² = cut is an ellipse. To draw it we diagonalise Σ = V Λ Vᵀ: the eigenvectors are the ellipse's axes and the eigenvalues their squared lengths. For a symmetric 2×2 the eigenvalues are a closed form from the trace and determinant, and the eigenvectors follow immediately. The semi-axes are √(λ · cut), so a larger cutoff (smaller contamination) inflates the ellipse.
    
        
    // eigen-decomposition of symmetric [[a,b],[b,c]] — closed form
function eig2(a, b, c) {
  const tr = a + c, det = a*c - b*b;
  const disc = Math.sqrt(Math.max(0, tr*tr/4 - det));
  const l1 = Math.max(tr/2 + disc, 1e-12);       // larger eigenvalue
  const l2 = Math.max(tr/2 - disc, 1e-12);       // smaller eigenvalue
  let vx, vy;
  if (Math.abs(b) > 1e-14) { vx = l1 - c; vy = b; }         // eigenvector of l1
  else if (a >= c)         { vx = 1; vy = 0; }
  else                     { vx = 0; vy = 1; }
  const nn = Math.hypot(vx, vy) || 1; vx /= nn; vy /= nn;
  return { l1, l2, v1x: vx, v1y: vy, v2x: -vy, v2y: vx };   // axes are orthonormal
}
// ellipse point at angle t on the boundary d² = cut
function ellipsePt(est, e, cut, t) {
  const r1 = Math.sqrt(e.l1 * cut), r2 = Math.sqrt(e.l2 * cut);
  return [ est.mx + Math.cos(t)*r1*e.v1x + Math.sin(t)*r2*e.v2x,
           est.my + Math.cos(t)*r1*e.v1y + Math.sin(t)*r2*e.v2y ];
}
    
      
    5. 
      
  5. 
        
    5
    Robust covariance — MCD by concentration (C-steps)
    
        
    The heart of the method. The Minimum Covariance Determinant estimate looks for the tight subset of h points whose covariance has the smallest determinant — the densest core, immune to outliers. We find it with concentration steps: from a current subset, compute μ, Σ, score all points, keep the h with smallest Mahalanobis distance, refit — each step provably shrinks the determinant. A few random starts avoid local minima; a final rescale by the median distance makes Σ consistent for Gaussian data so the chi-square cutoff stays honest.
    
        
    // Minimum-Covariance-Determinant location & scatter via C-steps
function mcd(pts, contamination) {
  const n = pts.length;
  const drop = Math.min(0.5, Math.max(contamination, 0.05));  // ≥ breakdown budget
  const h = Math.max(3, Math.min(n, Math.round((1 - drop) * n)));  // support size
  const all = [...Array(n).keys()];
  const rng = mulberry32(12345);
  const starts = [all];                              // + random h-subset starts
  for (let s = 0; s < 6; s++) {
    const sh = all.slice();
    for (let i = n-1; i > 0; i--) { const j = (rng()*(i+1))|0; [sh[i],sh[j]]=[sh[j],sh[i]]; }
    starts.push(sh.slice(0, h));
  }
  let best = null, bestDet = Infinity;
  for (const start of starts) {
    let idx = start.slice(), est = meanCov(pts, idx);
    for (let it = 0; it < 12; it++) {                // C-steps: shrink |Σ|
      const inv = inv2(est.cxx, est.cyy, est.cxy);
      const d = all.map(i => ({ i, d: maha2(pts[i].x-est.mx, pts[i].y-est.my, inv) }));
      d.sort((a, b) => a.d - b.d);                   // keep the h closest points
      idx = d.slice(0, h).map(o => o.i);
      est = meanCov(pts, idx);
    }
    const det = est.cxx*est.cyy - est.cxy*est.cxy;
    if (det < bestDet && isFinite(det)) { bestDet = det; best = { est, support: idx }; }
  }
  // consistency rescale: make the support's median d² match the χ²₂ median (1.386)
  const inv = inv2(best.est.cxx, best.est.cyy, best.est.cxy);
  const ds = best.support.map(i => maha2(pts[i].x-best.est.mx, pts[i].y-best.est.my, inv))
                         .sort((a, b) => a - b);
  const scale = (ds[ds.length >> 1] || 1) / 1.3862943611;
  if (isFinite(scale) && scale > 1e-9) { best.est.cxx*=scale; best.est.cyy*=scale; best.est.cxy*=scale; }
  best.est.support = best.support;
  return best.est;                                   // robust μ and Σ
}

  6.

    Putting it together — fit and flag
    
        
    The whole envelope is five calls: pick the estimator (robust MCD or plain empirical), invert Σ, score every point, get the chi-square cutoff, flag. This one function drives all three LOOK demos — the fitted ellipse, the plain-vs-robust contrast, and the distance-distance plot.
    
        
    function fitEnvelope(pts, contamination, robust) {
  const n = pts.length;
  const est = (robust && n >= 6) ? mcd(pts, contamination)
                                 : meanCov(pts, [...Array(n).keys()]);
  const inv = inv2(est.cxx, est.cyy, est.cxy);
  const cut = chiCut2(contamination);
  const d2  = pts.map(p => maha2(p.x - est.mx, p.y - est.my, inv));
  const flags = d2.map(d => d > cut);
  return { est, inv, cut, d2, flags };
}
// sanity: d²(μ) = 0 ; a point 6σ out gets a huge d² and is flagged;
// one gross outlier barely moves the robust ellipse but bloats the plain one.

    In practice — the standard tool
    
        
    You rarely hand-roll it. scikit-learn ships EllipticEnvelope, which fits a robust MinCovDet location and covariance under the hood, then flags by the chi-square cutoff at your contamination. It is a one-liner — and its one assumption is the same one you just coded: the inliers are a single Gaussian blob. For multi-modal or non-elliptical normal data you reach for a density- or distance-based detector instead.
    
        
    # scikit-learn — the robust Gaussian envelope in three lines
from sklearn.covariance import EllipticEnvelope

ee = EllipticEnvelope(contamination=0.1)   # robust MinCovDet + χ² cutoff
ee.fit(X)                                  # X: (n, 2) — assumes ONE Gaussian
labels = ee.predict(X)                     # +1 inlier, −1 outlier
dist   = ee.mahalanobis(X)                 # the same d² you computed by hand

The Elliptic Envelope is the parametric, robust-statistics corner of outlier detection: it commits to a single Gaussian model of "normal," which buys it a calibrated chi-square cutoff and a clean, interpretable Mahalanobis score — and the robust MCD covariance is what keeps that model from being sabotaged by the very outliers it is meant to catch (masking). It is the natural companion to Isolation Forest (Day 26), which makes no shape assumption at all, and to Local Outlier Factor and One-Class SVM, which trade the tidy statistical guarantee for flexibility. And it is the covariance-flavoured member of the robust-stats family you have been building — RANSAC (D51) makes a fit robust by consensus, Huber (D52) by down-weighting big residuals, Theil–Sen (D53) by taking a median of slopes; the Elliptic Envelope makes the covariance robust so the notion of "far" itself stops being fooled.

It joins RANSAC (D51), Huber (D52) and Theil–Sen (D53) in the robust-stats toolbox — the covariance/Mahalanobis method for detecting outliers. 👉 When your "normal" data is roughly one Gaussian cloud and you want a principled, calibrated outlier flag, reach for the Elliptic Envelope.
