🎯 Model Calibration — When "90% Confident" Is Right Only 70% of the Time: the Reliability Diagram Bins Predictions and Plots Mean-Predicted vs Actual-Fraction, Expected Calibration Error Sums the Weighted Gaps off the Diagonal, and Two Post-hoc Fixes — Platt Scaling (a Sigmoid Fit on a Holdout) and Isotonic Regression (a Monotonic Step Fit) — Bend the Curve Back Toward the Diagonal

A classifier can be accurate and still lie about its confidence. When a well-trained model says "90% sure this is spam", you would like it to be right about 90 times out of 100 — but modern models (boosted trees, deep nets) are famously overconfident: among the cases it stamped 0.9, the truth might be positive only 70% of the time. Calibration is about that promise — does a predicted probability match the observed frequency? The tool that reveals it is the reliability diagram: sort predictions into bins, plot each bin's mean predicted probability against the fraction that were actually positive. Perfect calibration sits on the 45° diagonal; a miscalibrated model bows away from it. Expected Calibration Error (ECE) turns that picture into one number — the size-weighted average vertical gap. Everything below bins real samples, computes ECE live, and fits Platt scaling and isotonic regression from scratch — no library.

🔨 Build it yourself

    
Calibration is post-processing: leave the classifier alone, learn a monotone map from its scores to honest probabilities on a holdout, and measure the improvement with ECE. Here is a runnable from-scratch core — reliability binning, Expected Calibration Error, Platt scaling by log-loss, isotonic regression via Pool-Adjacent-Violators, the honest fit-on-holdout / score-on-test protocol, and the real library.     1
    Bin predictions — build the reliability curve
    
        
    Sort the predicted probabilities into equal-width bins over [0,1]. For each bin record the mean predicted probability (conf) and the fraction of samples that were actually positive (acc). Plotting acc vs conf is the reliability diagram; the diagonal is perfect calibration.
    
        
    import numpy as np

def reliability(p, y, n_bins=12):
    edges = np.linspace(0, 1, n_bins + 1)
    idx = np.clip(np.digitize(p, edges) - 1, 0, n_bins - 1)
    rows = []
    for b in range(n_bins):
        m = idx == b
        if m.sum() == 0:
            continue
        rows.append(dict(conf=p[m].mean(),      # mean predicted prob
                         acc=y[m].mean(),        # observed positive fraction
                         n=int(m.sum())))
    return rows                                   # points on the diagram
# conf ~= acc on every bin  ->  points hug the diagonal  ->  well calibrated

    Expected Calibration Error — one number for the whole curve
    
        
    ECE is the size-weighted average vertical gap between each bin and the diagonal: how far, on average, a predicted probability is from the truth. MCE is the worst single bin. Both are 0 for a perfectly calibrated model.
    
        
    def ece(p, y, n_bins=12):
    edges = np.linspace(0, 1, n_bins + 1)
    idx = np.clip(np.digitize(p, edges) - 1, 0, n_bins - 1)
    N, e, mce = len(p), 0.0, 0.0
    for b in range(n_bins):
        m = idx == b
        if m.sum() == 0:
            continue
        gap = abs(p[m].mean() - y[m].mean())      # |conf - acc|
        e   += (m.sum() / N) * gap                # weight by bin count
        mce  = max(mce, gap)
    return e, mce

# accuracy answers "is the label right?"; ECE answers "is the PROBABILITY right?"
# a 95%-accurate model can still have a huge ECE if its confidences lie.

    Fix 1 — Platt scaling (fit a sigmoid on a holdout)
    
        
    Learn two parameters A, B so that σ(A·score + B) matches the labels, by minimizing log-loss on a calibration holdout. Using the logit of the model's probability as the score, A rescales confidence (a temperature) and B shifts the base rate. Platt's original trick smooths the targets to resist overfitting.
    
        
    def fit_platt(p_hold, y_hold, iters=800, lr=0.3):
    x = np.log(np.clip(p_hold, 1e-6, 1-1e-6) /
               np.clip(1-p_hold, 1e-6, 1-1e-6))   # score = logit(p)
    # Platt target smoothing (optional but classic):
    n1, n0 = y_hold.sum(), (1 - y_hold).sum()
    t = np.where(y_hold == 1, (n1+1)/(n1+2), 1/(n0+2))
    A, B = 1.0, 0.0
    for _ in range(iters):
        q  = 1 / (1 + np.exp(-(A*x + B)))          # calibrated prob
        gA = ((q - t) * x).mean(); gB = (q - t).mean()
        A -= lr*gA; B -= lr*gB
    return lambda p: 1/(1+np.exp(-(A*np.log(p/(1-p)) + B)))
# smooth, 2-parameter, low-variance -> great for small holdouts.

    Fix 2 — Isotonic regression (Pool Adjacent Violators)
    
        
    Fit the best non-decreasing step function mapping score → probability, minimizing squared error. Sort by score, then repeatedly merge any adjacent block whose value exceeds its right neighbour into a pooled (weighted-mean) block. The result is a monotone staircase — no shape assumption beyond "higher score ⇒ higher probability".
    
        
    def fit_isotonic(p_hold, y_hold):
    order = np.argsort(p_hold)
    xs, ys = p_hold[order], y_hold[order].astype(float)
    # PAV: stack of blocks (value, weight, x_lo, x_hi)
    stack = []
    for x, y in zip(xs, ys):
        cur = [y, 1.0, x, x]
        while stack and stack[-1][0] > cur[0]:          # violation -> pool
            v, w, lo, hi = stack.pop()
            tot = w + cur[1]
            cur = [(v*w + cur[0]*cur[1]) / tot, tot, lo, cur[3]]
        stack.append(cur)
    knots_x = [c[2] for c in stack] + [c[3] for c in stack[-1:]]
    knots_v = [c[0] for c in stack] + [stack[-1][0]]
    return lambda p: np.interp(p, [c[2] for c in stack], [c[0] for c in stack])
# flexible: corrects ANY monotone distortion, but needs more data than Platt.

    The honest protocol — fit on holdout, measure on test
    
        
    Never fit the calibrator on the training data the classifier already saw, and never report ECE on the same data you calibrated on — both leak and understate the error. Split off a calibration holdout, fit there, then measure ECE on a separate test set. Calibration is monotone, so it never changes the ranking — AUC and (near enough) accuracy are untouched; only the probabilities become trustworthy.
    
        
    # p_cal, y_cal = classifier's outputs on a HELD-OUT calibration set
# p_test, y_test = a separate test set the calibrator never saw
cal = fit_platt(p_cal, y_cal)          # or fit_isotonic(...)

print("raw ECE :", ece(p_test,        y_test)[0])
print("cal ECE :", ece(cal(p_test),   y_test)[0])   # should drop sharply
print("AUC unchanged:", auc(p_test, y_test) == auc(cal(p_test), y_test))
# calibration re-labels the confidence, not the decision boundary.

    Use the real library — and temperature scaling for nets
    
        
    In practice, wrap any classifier in scikit-learn's CalibratedClassifierCV (method "sigmoid" = Platt, "isotonic" = isotonic, with cross-validated holdouts built in). For deep nets, temperature scaling — dividing the logits by one learned scalar T — is the standard, near-free fix (a special case of Platt with B=0, one parameter).
    
        
    from sklearn.calibration import CalibratedClassifierCV, calibration_curve
from sklearn.metrics import brier_score_loss

cal = CalibratedClassifierCV(base_estimator=clf, method="isotonic", cv=5)
cal.fit(X_train, y_train)                       # holdouts handled internally
frac_pos, mean_pred = calibration_curve(y_test, cal.predict_proba(X_test)[:,1],
                                        n_bins=12)   # the reliability curve

# deep nets: temperature scaling — one scalar on the logits
#   T = argmin_T  NLL( softmax(logits / T),  y_val )
#   T > 1 softens overconfident logits; keeps argmax (accuracy) fixed.

🎉 Day 44 of MachineLearningFromZero done — probabilities you can actually bet on.
Accuracy asks "is the label right?"; calibration asks the harder question "is the probability right?" — and a 95%-accurate model can still be a confident liar. The reliability diagram exposes it by binning predictions and plotting mean-predicted vs actual-fraction: a calibrated model rides the 45° diagonal, an overconfident one sags below it (its 0.9s under-deliver) and an underconfident one climbs above. Expected Calibration Error compresses the whole curve into a single count-weighted gap. Two post-hoc fixes, both monotone so they never touch the ranking: Platt scaling fits a smooth 2-parameter sigmoid on a holdout — low variance, ideal for small data — and isotonic regression fits a free-form monotonic staircase via Pool-Adjacent-Violators — flexible but data-hungry. Fit on a holdout, measure ECE on separate test data, and the curve straightens while AUC stays put. 👉 Whenever a probability drives a decision — a medical risk, a fraud threshold, an expected-value bet — calibration is what makes the number mean what it says.
