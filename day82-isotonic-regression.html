MLFROMZERO · DAY 82

Isotonic regression — it cannot change your AUC by a single digit, and it will overfit a small validation set without blinking.

The closest non-decreasing sequence, exactly

Isotonic regression answers one question: of all non-decreasing sequences, which is closest to this data in least squares? Not approximately — exactly, in one left-to-right pass.

Checked against a search over every possible block partition

An isotonic fit is fully determined by how the positions are cut into blocks, since each block then takes its own mean. So for small inputs we can enumerate all 2n-1 cuts and pick the best monotone one — a completely different algorithm, used here only to prove the fast one right.

What it is actually for: calibration

A classifier can rank perfectly and still report numbers that are not probabilities. Isotonic regression maps scores to frequencies. Because the map is monotone, it cannot change the ranking — so AUC is untouched, by construction, and everything shows up in Brier score.

And the part the tutorials leave out

It is an exact projection, not a smoother. Nothing in it regularises. Given a small sample it will happily fit a step per point.

Out-of-sample Brier against in-sample, as the training set grows. The gap at n=40 is not noise — it is the method doing exactly what it was asked to do.

Pool adjacent violators, in full

One pass, a stack of blocks, and a while — because merging a violating pair can expose another violation underneath it.
