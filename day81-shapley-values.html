Shapley values — the only attribution that adds up, and the obvious alternative that hands two essential features a score of zero.

A prediction, split between the things that caused it

You have a model and one prediction. The question everyone asks is: how much of this number is down to each input? Shapley values answer it by asking a much more careful question — how much does this feature add, on average, over every possible order in which the features could have arrived?

Shapley against the thing everyone reaches for first

    

      The intuitive method is leave-one-out: drop a feature, see how much the
      prediction moves, call that its importance. It is one line of code and it is
      wrong in a specific, reproducible way.
    

    

    

  


  

    
The four properties, checked on every model here

    

      Shapley values are not a heuristic that happens to work. They are the
      unique attribution satisfying four requirements at once, and each one
      is checkable.
    

    

  






  

    
The definition, and why the weights look so strange

    

      For a feature i, the Shapley value is the average marginal
      contribution of i over all orderings of the features:
    

    
phi_i = sum over S not containing i of
            |S|! * (n - |S| - 1)! / n!  *  ( v(S + i) - v(S) )

    

      The factorial weight is not decoration. It is exactly the fraction of the
      n! orderings in which the set S arrives before
      i and everything else after. Summing over coalitions with that
      weight is the same as averaging over permutations — which is why the
      implementation can do either, and why the two agree to the last bit.
    

    

    

  


  

    
Where leave-one-out breaks

    

      Take a model that fires only when both features are present. Drop
      either one and the prediction falls to the floor — so leave-one-out
      scores them both as fully responsible, and the scores sum to twice the
      prediction. Now take a model with a redundant copy of a feature. Drop
      either copy and nothing moves at all, so leave-one-out scores both at zero,
      and the scores sum to nothing.
    

    

    

  


  

    
Exact, and the sampled approximation
