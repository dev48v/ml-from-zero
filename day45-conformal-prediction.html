🎯 Conformal Prediction — Turning a Point Guess into an Interval You Can Trust: Split (Inductive) Conformal Trains a Model, Scores Its Errors |y−ŷ| on a Held-out Calibration Set, Takes the ⌈(n+1)(1−α)⌉/n Empirical Quantile q — and the Band ŷ ± q Then Covers the Truth with Probability ≥ 1−α for Any Distribution (assuming only exchangeability), a Finite-Sample Guarantee No Other Method Gives

A model that only ever answers "the value is 3.2" is hiding how sure it is. Conformal prediction wraps any trained model in an interval — "the value is in [2.4, 4.0]" — that comes with a mathematical promise: the true value lands inside at least 90% of the time (or 95%, or whatever 1−α you ask for), and that promise holds for any data distribution, with finite data, no Gaussian assumption, no faith in the model being correct. The recipe is almost embarrassingly simple: train the model, look at how big its errors |y−ŷ| are on a fresh calibration set, take the right empirical quantile of those errors, and pad every prediction by it. Everything below computes that quantile and measures the resulting coverage live, from scratch — no library, no faking.

Pick a demo. Split-conformal band fits a regressor on a toy 1-D dataset, scores its calibration errors, and turns the α slider into a real quantile q — the shaded band is ŷ ± q, and a live readout shows the empirical coverage on a held-out test set tracking the target 1−α. The coverage guarantee sweeps α across its whole range and plots achieved-vs-target coverage: the points ride the diagonal, so the guarantee is real, not a fluke. Adaptivity puts a constant-width band next to a locally-normalized one — divide the error by an estimate of local spread and the interval widens where the model is unsure and pinches where it is confident, same coverage, smarter shape. 🔨 Build it yourself

    
Split (inductive) conformal prediction is a wrapper you can bolt onto any model in a dozen lines: split off a calibration set, score the model's errors on it, take one quantile, and pad every future prediction by it — with a proven ≥ 1−α coverage guarantee. Here is the runnable from-scratch core — the split, the nonconformity scores, the exact ⌈(n+1)(1−α)⌉/n quantile, the interval and its coverage check, the locally-adaptive (normalized) variant, and the real library. Everything the LOOK tab draws lives in these snippets.

    
    
      
  1. 
        
    1
    Split the data — train / calibrate / test
    
        
    The "split" in split conformal: carve a calibration set out of your data that the model never trains on. Fit the model on the training part only; the calibration part is a clean, exchangeable sample used to measure how big the errors really are. Test data is what you'll finally predict on.
    
        
    import numpy as np
rng = np.random.default_rng(0)

# X, y are your data. Shuffle then split three ways.
idx = rng.permutation(len(X))
tr, cal, te = np.split(idx, [int(.5*len(X)), int(.75*len(X))])

model.fit(X[tr], y[tr])          # model NEVER sees the calibration set
# cal = the exchangeable sample that earns the guarantee
# te  = fresh points we will wrap in an interval
    
      
    2. 
      
  2. 
        
    2
    Nonconformity scores — how "strange" is each point?
    
        
    A nonconformity score measures how badly the model fits a point. For regression the natural score is the absolute residual |y − ŷ|: large means the point disagrees with the model. Compute it on every calibration point — that distribution of "typical strangeness" is all conformal needs.
    
        
    yhat_cal = model.predict(X[cal])
scores   = np.abs(y[cal] - yhat_cal)     # nonconformity = |y - yhat|

# scores is an empirical picture of how big errors normally are.
# (any score works: |y-yhat|, |y-yhat|/sigma(x), 1 - softmax prob, ...)
    
      
    3. 
      
  3. 
        
    3
    The conformal quantile — the ⌈(n+1)(1−α)⌉ rank
    
        
    This is the whole trick. Sort the calibration scores and take the ⌈(n+1)(1−α)⌉-th smallest. The +1 (a "phantom" for the unseen test point) is what upgrades an ordinary quantile into a finite-sample guarantee. If that rank exceeds n, you don't have enough calibration data for that α and q is +∞ (an infinite, useless-but-honest interval).
    
        
    def conformal_quantile(scores, alpha):
    n = len(scores)
    k = int(np.ceil((n + 1) * (1 - alpha)))    # the magic rank
    if k > n:                                   # too little data for this alpha
        return np.inf
    return np.sort(scores)[k - 1]               # k-th smallest (1-indexed)

q = conformal_quantile(scores, alpha=0.1)       # e.g. 90% target
# k/n is ~ the (1-alpha) empirical quantile, nudged up by the +1.
    
      
    4. 
      
  4. 
        
    4
    The interval ŷ ± q — and check the coverage
    
        
    Pad every prediction by q: the interval is [ŷ − q, ŷ + q]. The theorem says the true y lands inside with probability at least 1 − α. Verify it empirically on the test set — the fraction covered should sit at or just above the target, whatever the data looks like.
    
        
    yhat_te = model.predict(X[te])
lo, hi  = yhat_te - q, yhat_te + q          # the prediction interval

covered = np.mean((y[te] >= lo) & (y[te] <= hi))
print(f"target {1-alpha:.2f}  ->  empirical coverage {covered:.3f}")
# covered >= 1 - alpha, distribution-free, no Gaussian assumption.
# width 2q is the price: honest uncertainty in the model's own units.
    
      
    5. 
      
  5. 
        
    5
    Adaptivity — normalize by local spread
    
        
    A constant q is one-size-fits-all, so it wastes width where the model is confident and undershoots where it isn't. Fit a second model σ̂(x) to the size of the residuals, then score |y−ŷ|/σ̂(x). Now the interval is ŷ ± q·σ̂(x) — same marginal guarantee, but it breathes with the local uncertainty.
    
        
    # mu = model.predict ; fit a spread model on |residual|
resid   = np.abs(y[tr] - model.predict(X[tr]))
sigma.fit(X[tr], resid)                         # sigma(x) ~ local error size

s_cal = np.abs(y[cal] - model.predict(X[cal])) / (sigma.predict(X[cal]) + 1e-6)
q = conformal_quantile(s_cal, alpha)            # quantile of NORMALIZED scores

lo = model.predict(X[te]) - q * sigma.predict(X[te])
hi = model.predict(X[te]) + q * sigma.predict(X[te])   # width varies with x
    
      
    6. 
      
  6. 
        
    6
    Use the real library — MAPIE, and classification sets
    
        
    In practice reach for MAPIE (regression and classification) or crepes: they handle the split, the quantile, cross-conformal for data efficiency, and normalized/CQR variants. For classification the same idea produces a prediction set — a set of labels guaranteed to contain the true class with probability 1−α (APS / RAPS / LAC scores), which naturally grows on hard, ambiguous inputs.
    
        
    from mapie.regression import MapieRegressor
mapie = MapieRegressor(estimator=model, method="base", cv="split")
mapie.fit(X_tr, y_tr)
y_pred, y_pis = mapie.predict(X_te, alpha=0.1)   # y_pis[:,0], y_pis[:,1] = [lo,hi]

# classification: a guaranteed-coverage prediction SET of labels
from mapie.classification import MapieClassifier
clf = MapieClassifier(estimator=model, method="aps", cv="split").fit(X_tr, y_tr)
y_hat, y_set = clf.predict(X_te, alpha=0.05)      # set covers true label 95%+

🎉 Day 45 of MachineLearningFromZero done — a prediction you can put a probability on.
A point prediction hides its own uncertainty; conformal prediction replaces it with an interval (or a set of labels) that carries a real, finite-sample coverage guarantee. Split conformal is the whole recipe in four moves: train any model, score its errors |y−ŷ| on a held-out calibration set, take the ⌈(n+1)(1−α)⌉/n empirical quantile q, and predict ŷ ± q. The magic is that this covers the truth with probability ≥ 1−α for any distribution and any model — the only assumption is exchangeability, and the +1 in the rank is what makes it exact in finite samples. α is the single knob: shrink it for tighter guarantees (wider bands), grow it for narrower bands (weaker guarantees). Plain conformal gives constant width; normalized scores |y−ŷ|/σ̂(x) make the band adapt — widening where the model is unsure. 👉 Whenever a prediction feeds a real decision — a dosage, a price, a risk threshold — conformal turns "my best guess is 3.2" into "it's in [2.4, 4.0], and I'm 90% sure", with the math to back the claim.
